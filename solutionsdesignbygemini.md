# 🎨 Solution Design: AI-Driven Design System (Gemini + Stitch + Archon)

**Date:** 2025-11-21
**Context:** Evolution of Archon Workflow (V6.2.1 -> V6.3.0) to integrate AI-driven design.

---

## 1. Vision: "Design as a Commodity"

The goal is to decouple the **Visual Identity** (Design) from the **Technical Implementation** (Code).
- **Code:** Remains stable, secure, and robust (Archon Architecture).
- **Design:** Becomes injectable, interchangeable, and generated by AI in minutes, not days.
- **Result:** "Wow" factor of a custom design with the speed of a template.

---

## 2. The Stack & Roles

| Tool | Role | Metaphor | Function |
| :--- | :--- | :--- | :--- |
| **Google Stitch** | **The Artist** (Right Brain) | "Visual Explorer" | Generates visual concepts, explores moods, creates the "Wow" look. Used for **Inspiration**. |
| **Gemini 3.0 Pro** | **The Architect** (Left Brain) | "Systematizer" | Analyzes visuals (Stitch/Brief), extracts rules, generates `design-tokens.json` (The Contract). |
| **Archon** | **The Builder** (Hands) | "Constructor" | Builds the app using the tokens. Enforces Quality Gates, Security, and Architecture. |

---

## 3. Workflow V6.2.1: The "Manual Pilot" (Immediate Action)

We will test this workflow manually on the **AI Agency Landing Page** project.

### Phase A: Exploration (Stitch)
1.  User goes to [stitch.withgoogle.com](https://stitch.withgoogle.com/).
2.  Prompt: "Agency landing page, minimal, dark mode, neon purple accents, linear-style".
3.  Output: A visual concept that pleases the user.
4.  **Artifact:** Screenshot or Figma export.

### Phase B: Systematization (Gemini)
1.  User provides the Stitch artifact + Project Brief to Gemini.
2.  Gemini analyzes and extracts:
    - **Palette:** HSL values (Primary, Secondary, Backgrounds).
    - **Typography:** Font family, weights, sizes.
    - **Spacing/Radius:** The mathematical rhythm.
3.  Gemini generates **3 Variants** of `design-tokens.json` (e.g., V1 Safe, V2 Bold, V3 Experimental).

### Phase C: Implementation (Archon)
1.  User selects the best variant (e.g., V2).
2.  Run `/speckit.final` (or manual build).
3.  Archon builds the React components using the tokens.
4.  **Validation:** Deploy to Vercel to see the *real* result (no AI mockups).

## 4. Proposed Infrastructure Changes (Archon V6.3)

To automate this, we will introduce:

### A. New Directory Structure
```text
my-project/
├── .design/                  # 🆕 New Directory
│   ├── brief-template.md     # Standardized input for AI
│   ├── tokens-history/       # Version control for design iterations
│   │   ├── v1-trust-blue.json
│   │   └── v2-tech-purple.json
│   └── stitch-references/    # 🆕 Place to drop Stitch screenshots
├── design-tokens.json        # The active "Contract"
└── ...
```

### B. New Command: `/speckit.design-ai`
*   **Input:** `.design/brief-template.md` + Optional Stitch screenshot.
*   **Process:** Calls Gemini 3.0 Pro via Zen MCP.
*   **Output:** Generates 3 token variants + 3 Vercel Preview URLs.
*   **Selection:** User picks one -> updates `design-tokens.json`.
