# Design Tokens TrustBoost

Les design tokens sont les valeurs atomiques qui définissent l'identité visuelle de TrustBoost.
Ils garantissent la cohérence à travers toutes les plateformes et composants.

## Principe des Design Tokens

Les design tokens suivent une approche **CSS-first** inspirée des patterns Context7 :

```css
@theme {
  /* Polices */
  --font-display: "Satoshi", "Inter", "system-ui", "sans-serif";
  --font-body: "Inter", "system-ui", "sans-serif";
  
  /* Breakpoint personnalisé */
  --breakpoint-3xl: 120rem;
  
  /* Couleurs OKLCH pour la cohérence perceptuelle */
  --color-primary-500: oklch(0.56 0.20 220);
  
  /* Animations fluides */
  --ease-fluid: cubic-bezier(0.3, 0, 0, 1);
  --ease-snappy: cubic-bezier(0.2, 0, 0, 1);
}
```

## Usage en CSS

### Variables CSS Natives

```css
:root {
  /* Pattern Context7 - Design tokens */
  --font-display: "Satoshi", "Inter", "system-ui", "sans-serif";
  --breakpoint-3xl: 120rem;
  --color-primary-500: oklch(0.56 0.20 220);
  --ease-fluid: cubic-bezier(0.3, 0, 0, 1);
}
```

### Utilisation avec Tailwind

```tsx
// Classes utilitaires
<div className="bg-primary-500 text-white rounded-lg p-6 shadow-md">

// Variables CSS arbitraires
<div className="bg-[var(--color-primary-500)] rounded-[12px]">

// Breakpoints personnalisés  
<div className="grid-cols-2 3xl:grid-cols-6">
```

### JavaScript/TypeScript

```tsx
import { tokens, getColor, getSpacing } from '@trustboost/design-system';

// Accès direct aux tokens
const primaryColor = tokens.colors.primary[500];
const mediumSpacing = tokens.spacing[4];

// Avec utilitaires
const warningColor = getColor('warning', 500);
const largeSpacing = getSpacing(8);
```
